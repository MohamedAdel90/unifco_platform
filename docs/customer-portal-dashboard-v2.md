# Customer Portal Dashboard V2

Customer 360 executive dashboard refinement.

- Unified customer scope and compact executive header
- Unified request quick actions with preselected service types
- Action-required summary
- Operational KPIs
- Service Request Journey and Priority Today
- Asset Health and Upcoming Visits
- Contracts & SLA and Financial Summary
- Recent Relationship Activity
- Responsive layout

The dashboard continues to use server-authorized customer-scoped data and does not introduce per-user content partitioning inside the unified customer account.
